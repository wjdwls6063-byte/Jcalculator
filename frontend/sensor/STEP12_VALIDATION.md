## 이번 요청 반영
EE-SX47/67의 8가지 설치 형상 선택 카드에 `ⓘ`를 추가했습니다.

- PC: `ⓘ` Hover → 해당 형상의 OMRON 한글 공식 카탈로그 이미지 팝업
- 모바일/터치: `ⓘ` Tap → 동일 팝업
- 형상 카드 클릭 → 형상 선택
- `ⓘ` 클릭 → 설명/이미지만 표시
- 이미지 출처: 사용자 제공 OMRON EE-SX47/67 한글 공식 카탈로그 2010, p.1170

## STEP 12에서 수정한 오류 가능 요소
1. `IP67 필요`를 실제 필터에 연결했습니다.
   - E3T: IP67 모델 유지
   - EE-SX47/67: IP50이므로 자동 제외
2. 선택 UI처럼 보이지만 로직이 없던 `최소 검출 물체`, `응답시간` 체크박스를 제거했습니다.
   - 해당 값은 제품 상세보기의 공식 사양에서 확인하도록 변경했습니다.
3. 공식 이미지 8개는 프로젝트 내부에 별도 파일로 저장하여 이후 다른 채팅/AI에서도 동일하게 사용할 수 있게 했습니다.

## 아직 필요한 확인
현재 실행 환경의 Chromium이 로컬/내부 페이지 탐색에서 관리자 차단 또는 Headless 대기 상태가 발생하여 **자동 브라우저 클릭 검증은 완료하지 못했습니다.**
따라서 이번 빌드는 데이터/로직/정적 구조 검증까지 완료된 상태이며, 실제 브라우저에서 아래 항목은 미리보기로 최종 확인해야 합니다.

- Hover 팝업 위치
- 모바일 Tap 팝업
- 작은 화면의 카드 줄바꿈
- Wizard를 처음부터 끝까지 실제 클릭했을 때의 체감 흐름

이 확인 후 `frontend/sensor/` 통합 단계로 진행합니다.

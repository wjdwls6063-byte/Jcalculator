## OMRON 데이터 출처 고정 원칙
1. 제품/사양 근거는 **OMRON 한국 공식 사이트(ia.omron.co.kr)** 와 **OMRON 한글 공식 카탈로그**만 사용한다.
2. 대리점, 판매점, 쇼핑몰, 블로그/카페, 서드파티 DB, 비공식 미러는 제품 공식 사양 근거로 사용하지 않는다.
3. 현재 E3T 기준 자료는:
   - OMRON 한국 공식 웹페이지
   - E3T 한글 종합 카탈로그 2010
4. 최신 한글 공식 카탈로그가 추후 첨부/확보되면:
   - 기존 데이터를 바로 덮어쓰지 않는다.
   - 구판과 신판의 모델/사양/액세서리/단종·수주종료 상태를 비교한다.
   - 변경 이력을 남기고 source version을 갱신한다.
5. 현행 여부가 공식자료로 확인되지 않은 모델은 기본 자동 추천에서 제외한다.
6. 중요한 제품 사양에는 📖 공식 근거를 연결한다. 가능하면 표/그래프/도면의 해당 부분만 Crop해서 표시한다.

## 한글판 우선 정책
- 더 최신의 영문/일문 자료가 존재하더라도 사용자의 별도 허용이 없는 한 OMRON 제품 데이터의 기준 문서는 **한글 공식자료 우선**으로 한다.
- 최신 한글판을 사용자가 제공하면 그 문서를 기준으로 STEP 10 데이터를 재검증/업데이트한다.

## 비교 기능
- 동일 제조사: 센서 종류 → 검출 방식 → 유사 시리즈/모델 그룹으로 비교
- 타 제조사: 공통 비교 스키마(detection method, distance, output, operation, shape, connection, response, IP 등)로 연결
- 제조사 고유 기능은 억지로 공통화하지 않고 별도 특징으로 유지
- 타 제조사 데이터는 해당 제조사 공식자료 단계에서 별도로 수집한다.

## 초보자/실무자 UX
- 초보자: 실제 사용 조건 중심 Wizard
- 실무자: 기술 용어 중심 Dynamic Filter

- ⓘ = 쉬운 용어/원리 설명 + 이미지
- 📖 = 공식 카탈로그/공식 사이트 근거

## 추가 카탈로그: EE-SX47/67
- 사용자 제공 파일: sources/OMRON_EE-SX47_67_2010_KOR.pdf
- OMRON 한글 공식 카탈로그 2010
- 분류: 포토마이크로센서 → 말굽형 → 투과형
- 공통 검출 홈 폭: 5mm
- 표준 검출 물체: 2×0.8mm 이상의 불투명체
- 응차: 0.025mm 이하
- 전원: DC5~24V±10%
- 응답 주파수: 1kHz 이상(평균 3kHz)
- 보호 구조: IP50
- 8가지 본체 형상
- EE-SX47: 커넥터 타입 / 입광 시 ON 고정 계열
- EE-SX67: 입광/차광 ON 전환 가능 계열 + 코드 인출 1m / 커넥터 중계 0.1m 계열
- 총 68개 주문 형식 레코드로 데이터화

## 선정 방식 추가
초보자 Wizard의 설치 환경 단계에서 가장 먼저:
'워크·도그·플래그가 센서의 5mm 홈 사이를 지나갈 수 있는가?'를 묻는다.

YES:
- 포토마이크로센서(EE-SX47/67) 경로
- 일반 광전센서 거리 질문 생략
- 8가지 형상 → NPN/PNP → 입광/차광 ON → 접속 방식 순으로 선정

NO:
- 기존 E3T 광전센서 경로
- 투과/회귀/확산/BGS/한정 반사 방식 선정

UNKNOWN:
- 전문가 필터/통합 검색에서 두 제품군을 함께 비교 가능

## 환경 주의
EE-SX47/67은 IP50이며 카탈로그에 방수·방진 구조가 아니고 물/기름 부착 환경에서 사용하지 말라고 명시되어 있으므로,
향후 환경 필터에서 IP67 필요 조건이 들어오면 자동 제외해야 한다.
